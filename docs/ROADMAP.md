# 개발 순서 (로드맵)

**목표**: 처음 요청한 기능을 먼저 완성한다.
1. 앱에서 2D 기계 도면을 그리면 3D가 자동으로 만들어진다 (최우선)
2. 도면 이미지를 올리면 인식해서 3D로 바꾼다
3. 3D를 다시 2D 도면으로 바꾼다
4. 노트북에서 쓰기 좋은 CAD 화면 (다른 CAD 앱 참고)

AI 기능은 위 기능이 완성된 뒤에 붙인다. (지금 있는 ‘AI 설계 검토’ 버튼은 시험용으로 그대로 둔다.)

## 1단계에서 만든 것

- **모서리(E)**: 꼭짓점 클릭 → R(둥글게) 또는 C(모따기). 같은 값으로 다시 클릭하면 해제, Shift+클릭이면 그 도형의 모든 꼭짓점. 크기는 리본에서 입력.
- **변 휘기**: 사각형/다각형을 선택하면 변 가운데에 ◆ 손잡이가 생기고, 끌면 그 점을 지나는 원호가 된다(반원까지). 사각형은 자동으로 다각형으로 바뀐다.
- **장공(S)**: 한쪽 끝 중심 → 다른 쪽 끝 중심으로 끌기. 그리는 중 `20,6`(중심거리,폭) 입력 가능. 손잡이로 두 중심과 폭을 조절.
- **대칭 복사 / 직선 배열 / 원형 배열**: 속성 패널의 ‘복사’ 칸. 기준선·중심의 기본값은 부품 가운데.
- **측정(M)**: 두 점 클릭 → 거리, 각도, 가로·세로 성분. 점·중심·정렬선에 붙는다.
- 내부 구조: 모든 도형을 “직선 + 원호(bulge)” 외곽선 하나로 다루도록 바꿈. 화면, 3D 생성, 검사가 같은 외곽선을 쓴다. 각진 구멍 경고는 R을 준 꼭짓점을 빼고 알려 준다.

## 2단계에서 만든 것

- **깊이**: 구멍(원·사각형·다각형·장공)마다 ‘관통’ 또는 깊이(mm)를 지정. 깊이는 그 뷰에서 보이는 가장 바깥 면부터 잰다
  (정면도는 앞면, 평면도는 윗면, 우측면도는 오른쪽 면). 막힌 구멍·포켓은 2D에서 옅게 칠해 관통 구멍과 구분.
  가장자리에 걸친 포켓은 단차(계단)가 된다.
- **구멍 도구(D)**: 클릭하면 규격 구멍이 놓인다. 오른쪽 ‘구멍 설정’에서 용도(볼트 관통 정밀·보통·거침 / 탭 / 직접),
  나사 규격(M2~M20), 머리 자리(카운터보어·카운터싱크), 깊이, 드릴 끝(118°)을 고른다.
  지름과 머리 자리 치수는 표준표(ISO 273 = KS B 1007, 탭 기초 구멍, ISO 4762 볼트용 자리파기, ISO 10642 접시머리)에서 자동으로 채우고 직접 고칠 수 있다.
- **옆으로 뚫는 구멍**: 몸체를 그리지 않은 뷰에 구멍만 그리면 그 방향으로 뚫는다 (예: 판의 우측면도에 가로 구멍).
  회전체 모드에서도 평면도·우측면도에 구멍을 그릴 수 있어 플랜지 볼트 구멍을 만들 수 있다.
- **결과 겹쳐 보기**: 3D 결과를 각 2D 창에 흐리게(외형선 + 숨은선) 겹쳐 보여 준다. 몸체가 없는 뷰에서 구멍 위치를 잡기 쉽고,
  결과 윤곽의 끝과 가운데에 스냅된다. 상태 표시줄에서 끄고 켤 수 있다.
- **검사 추가**: 카운터보어·카운터싱크 지름/깊이 오류, 머리 자리까지 포함한 가장자리 거리, 깊고 좁은 포켓(깊이/폭 > 4),
  탭 물림 길이(호칭의 1.5배 미만), 깊이가 두께 이상이라 관통되는 경우, 회전체 모드에서 무시되는 몸체.
- 예제: ‘가이드 블록(깊이·카운터보어·가로 탭)’, ‘플랜지(회전체 + 볼트 구멍)’.
- 3D 만드는 방법: 몸체 단면(관통 구멍 포함)으로 먼저 3D를 만든 뒤, 깊이·머리 자리가 있는 구멍은 바깥 면부터 도구 형상으로 판다.
  원형 구멍은 (반지름, 깊이) 단면을 구멍 축으로 360° 돌려 몸통·머리 자리·드릴 끝을 한 번에 만든다.

## 화면 재설계

- 위쪽 탭(또는 1/2/3): **2D 설계 · 3D 보기 · 도면 출력**. 2D와 3D를 한 화면에 섞지 않는다.
- 2D 설계는 큰 제도판 한 장: 정면도(왼쪽 아래)·평면도(위)·우측면도(오른쪽)를 실제 도면처럼 배치.
  X·Z는 항상 일직선, 오른쪽 위 45° 연결선이 평면도와 우측면도의 깊이(Y)를 잇는다. [전체|정면|평면|우측]으로 한 뷰만 크게.

## 3단계에서 만든 것

- **변수**: 왼쪽 아래 ‘변수’ 칸에서 `L = 80`, `t = 6`, `e = L/10`처럼 이름 붙은 값을 만든다. 변수끼리 참조 가능, 서로 돌고 도는 참조는 오류로 알려 준다.
  이름을 바꾸면 그 변수를 쓰는 식도 함께 바뀐다.
- **식으로 치수 입력**: 속성 패널의 치수 칸, 두께 칸, 구멍 깊이 칸에 숫자 대신 식을 넣을 수 있다 (`L`, `L/2`, `L-e`, `t*2`, `sqrt(a^2+b^2)`, `max(t,3)`).
  식에 묶인 치수는 파란 칸 + `fx`로 보이고, 변수를 바꾸면 다시 계산되어 3D까지 바로 바뀐다.
- **치수 잠금(🔒)**: 지금 값으로 잠그면 도형을 끌어도 그 치수는 바뀌지 않는다. 한 번 더 누르면 해제.
- **도면 위 치수**: 도형을 선택하면 크기와 원점부터의 위치가 치수선으로 보이고, 숫자를 누르면 그 자리에서 값이나 식을 입력할 수 있다.
- **가운데 맞춤**: 선택한 도형을 부품 가운데로 (가로/세로). **거의 수평·수직인 변 바로잡기**: 5° 안쪽으로 기울어진 다각형 변을 정확히 맞춘다.
- 식 오류(없는 변수, 0으로 나누기, 순환 참조)는 설계 검사에 오류로 나오고, 그 치수는 마지막 값을 그대로 쓴다.
- 예제: ‘변수로 만드는 판’ — L·W·t·e를 바꾸면 판 크기, 구멍 위치(가장자리에서 e), 장공 길이(L/3)가 함께 바뀐다.
- 참고: 다각형 꼭짓점은 아직 식에 묶을 수 없고, 도형끼리의 구속(예: 두 구멍 간격 고정)은 변수로 표현한다.
