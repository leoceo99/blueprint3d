## 1단계에서 만든 것

- **모서리(E)**: 꼭짓점 클릭 → R(둥글게) 또는 C(모따기). 같은 값으로 다시 클릭하면 해제, Shift+클릭이면 그 도형의 모든 꼭짓점. 크기는 리본에서 입력.
- **변 휘기**: 사각형/다각형을 선택하면 변 가운데에 ◆ 손잡이가 생기고, 끌면 그 점을 지나는 원호가 된다(반원까지). 사각형은 자동으로 다각형으로 바뀐다.
- **장공(S)**: 한쪽 끝 중심 → 다른 쪽 끝 중심으로 끌기. 그리는 중 `20,6`(중심거리,폭) 입력 가능. 손잡이로 두 중심과 폭을 조절.
- **대칭 복사 / 직선 배열 / 원형 배열**: 속성 패널의 ‘복사’ 칸. 기준선·중심의 기본값은 부품 가운데.
- **측정(M)**: 두 점 클릭 → 거리, 각도, 가로·세로 성분. 점·중심·정렬선에 붙는다.
- 내부 구조: 모든 도형을 “직선 + 원호(bulge)” 외곽선 하나로 다루도록 바꿈. 화면, 3D 생성, 검사가 같은 외곽선을 쓴다. 각진 구멍 경고는 R을 준 꼭짓점을 빼고 알려 준다.

## 2단계에서 만든 것

- **깊이**: 구멍(원·사각형·다각형·장공)마다 ‘관통’ 또는 깊이(mm)를 지정. 깊이는 그 뷰에서 보이는 가장 바깥 면부터 잰다
  (정면도는 앞면, 평면도는 윗면, 우측면도는 오른쪽 면). 막힌 구멍·포켓은 2D에서 옅게 칠해 관통 구멍과 구분.
  가장자리에 걸친 포켓은 단차(계단)가 된다.
- **구멍 도구(D)**: 클릭하면 규격 구멍이 놓인다. 오른쪽 ‘구멍 설정’에서 용도(볼트 관통 정밀·보통·거침 / 탭 / 직접),
  나사 규격(M2~M20), 머리 자리(카운터보어·카운터싱크), 깊이, 드릴 끝(118°)을 고른다.
  지름과 머리 자리 치수는 표준표(ISO 273 = KS B 1007, 탭 기초 구멍, ISO 4762 볼트용 자리파기, ISO 10642 접시머리)에서 자동으로 채우고 직접 고칠 수 있다.
- **옆으로 뚫는 구멍**: 몸체를 그리지 않은 뷰에 구멍만 그리면 그 방향으로 뚫는다 (예: 판의 우측면도에 가로 구멍).
  회전체 모드에서도 평면도·우측면도에 구멍을 그릴 수 있어 플랜지 볼트 구멍을 만들 수 있다.
- **결과 겹쳐 보기**: 3D 결과를 각 2D 창에 흐리게(외형선 + 숨은선) 겹쳐 보여 준다. 몸체가 없는 뷰에서 구멍 위치를 잡기 쉽고,
  결과 윤곽의 끝과 가운데에 스냅된다. 상태 표시줄에서 끄고 켤 수 있다.
- **검사 추가**: 카운터보어·카운터싱크 지름/깊이 오류, 머리 자리까지 포함한 가장자리 거리, 깊고 좁은 포켓(깊이/폭 > 4),
  탭 물림 길이(호칭의 1.5배 미만), 깊이가 두께 이상이라 관통되는 경우, 회전체 모드에서 무시되는 몸체.
- 예제: ‘가이드 블록(깊이·카운터보어·가로 탭)’, ‘플랜지(회전체 + 볼트 구멍)’.
- 3D 만드는 방법: 몸체 단면(관통 구멍 포함)으로 먼저 3D를 만든 뒤, 깊이·머리 자리가 있는 구멍은 바깥 면부터 도구 형상으로 판다.
  원형 구멍은 (반지름, 깊이) 단면을 구멍 축으로 360° 돌려 몸통·머리 자리·드릴 끝을 한 번에 만든다.

## 화면 재설계

- 위쪽 탭(또는 1/2/3): **2D 설계 · 3D 보기 · 도면 출력**. 2D와 3D를 한 화면에 섞지 않는다.
- 2D 설계는 큰 제도판 한 장: 정면도(왼쪽 아래)·평면도(위)·우측면도(오른쪽)를 실제 도면처럼 배치.
  X·Z는 항상 일직선, 오른쪽 위 45° 연결선이 평면도와 우측면도의 깊이(Y)를 잇는다. [전체|정면|평면|우측]으로 한 뷰만 크게.

## 3단계에서 만든 것

- **변수**: 왼쪽 아래 ‘변수’ 칸에서 `L = 80`, `t = 6`, `e = L/10`처럼 이름 붙은 값을 만든다. 변수끼리 참조 가능, 서로 돌고 도는 참조는 오류로 알려 준다.
  이름을 바꾸면 그 변수를 쓰는 식도 함께 바뀐다.
- **식으로 치수 입력**: 속성 패널의 치수 칸, 두께 칸, 구멍 깊이 칸에 숫자 대신 식을 넣을 수 있다 (`L`, `L/2`, `L-e`, `t*2`, `sqrt(a^2+b^2)`, `max(t,3)`).
  식에 묶인 치수는 파란 칸 + `fx`로 보이고, 변수를 바꾸면 다시 계산되어 3D까지 바로 바뀐다.
- **치수 잠금(🔒)**: 지금 값으로 잠그면 도형을 끌어도 그 치수는 바뀌지 않는다. 한 번 더 누르면 해제.
- **도면 위 치수**: 도형을 선택하면 크기와 원점부터의 위치가 치수선으로 보이고, 숫자를 누르면 그 자리에서 값이나 식을 입력할 수 있다.
- **가운데 맞춤**: 선택한 도형을 부품 가운데로 (가로/세로). **거의 수평·수직인 변 바로잡기**: 5° 안쪽으로 기울어진 다각형 변을 정확히 맞춘다.
- 식 오류(없는 변수, 0으로 나누기, 순환 참조)는 설계 검사에 오류로 나오고, 그 치수는 마지막 값을 그대로 쓴다.
- 예제: ‘변수로 만드는 판’ — L·W·t·e를 바꾸면 판 크기, 구멍 위치(가장자리에서 e), 장공 길이(L/3)가 함께 바뀐다.
- 참고: 다각형 꼭짓점은 아직 식에 묶을 수 없고, 도형끼리의 구속(예: 두 구멍 간격 고정)은 변수로 표현한다.

## 4단계에서 만든 것

- **용지와 척도**: A4/A3/A2(가로)와 표준 척도(5:1 ~ 1:50). ‘자동’이면 1:1이 들어가는 가장 작은 용지를 고르고, 작은 부품은 확대 척도,
  큰 부품은 축소 척도를 고른다. 세 뷰는 3각법 위치에 맞춰 놓고(X·Z 일직선), 치수 자리를 비워 둔다.
- **구멍 지시**: 같은 구멍끼리 묶어 “4×M5 관통구멍 Ø5.5 관통”, “M5 탭 깊이 12”, “2×M6 관통구멍 Ø6.6 · 카운터보어 Ø11 깊이 6.5”처럼
  지시선으로 적는다. 지시는 뷰 밖 빈 곳에 놓고, 지시선은 묶음에서 글자에 가장 가까운 구멍에서 나온다.
- **볼트 원(PCD)**: 같은 원형 구멍 3개 이상이 한 원 위에 같은 간격이면 “6×M6 … PCD Ø60 등배치”로 적고 볼트 원을 중심선으로 그린다.
- **위치 치수**: 구멍 중심은 왼쪽 아래 모서리 기준 좌표 치수(0, 12, 68 …), 그 바깥에 전체 크기 치수.
- **중심선**: 구멍마다 십자 중심선, 다른 뷰에서는 구멍 축 중심선, 회전체는 회전축.
- **표제란**: 부품명, 척도·용지, 재질, 수량, 투상법(3각법)·단위, 일반 공차(기본 KS B ISO 2768-m), 설계자, 날짜. 주기는 왼쪽 위.
  도면 출력 화면 왼쪽 ‘도면 설정’에서 고치고, 프로젝트 파일에 함께 저장된다.
- **인쇄 / PDF**: 용지 크기를 인쇄 설정에 넘겨서 그 용지 한 장에, 여백 없이, 실제 척도로 찍힌다.
- **DXF**: 실제 크기(1:1, mm)로 저장. 원과 원호는 CIRCLE/ARC 그대로, 레이어(외형선 VISIBLE, 숨은선 HIDDEN, 중심선 CENTER, 치수 DIM, 테두리 FRAME)와
  선 종류(HIDDEN, CENTER)를 나눈다. 한글은 `\U+XXXX`, Ø는 `%%c`로 적어 AutoCAD에서 깨지지 않는다.
- 아직 안 한 것: 단면도, 공차·끼워맞춤 기호, 표면 거칠기 기호 (도면 이미지 → 3D 다음에 다시 본다).

## 전체 기능 검토 (4단계 뒤)

브라우저 자동화(Playwright)로 실제 화면을 눌러 보며 확인했다: 빈 프로젝트, 모든 그리기 도구와 치수 입력, 잘못된 입력, 실행 취소·다시 실행,
복제·삭제·끌기 이동, 모서리·휜 변, 측정, 변수·식·순환 참조, 두께 식, 회전체, 저장·열기·망가진 파일, STL·STEP·SVG·DXF 내보내기,
예제 6개, 검사 결과 클릭, 초점 버튼·3D 시점, 실패하는 형상(꼬인 다각형, 겹치지 않는 뷰, 몸체보다 큰 구멍), 어두운 화면, 1280~1920 화면, 구멍 126~240개 부품.

고친 것:
- **구멍이 많으면 느림** → 몸체 안에 완전히 들어 있는 원·장공 구멍은 2D 불리언 대신 면의 안쪽 경계로 바로 넣고, 나머지는 3D에서 한꺼번에 뺀다.
  구멍 126개 판: 7.6초 → 3.3초, 240개: 12.4초 → 7.2초 (남은 시간은 대부분 숨은선 계산). 예제 6개는 부피·외곽·투영선이 이전과 같다.
- **자동 저장이 망가져 있으면 오류** → 불러올 때 프로젝트를 검사해서 망가진 도형은 빼고 빠진 값은 채운다 (열기 파일도 같음).
- **DXF의 한글이 AutoCAD에서 깨질 수 있음** → `\U+XXXX`·`%%c`로 저장. ezdxf로 6개 예제 DXF를 읽어 오류 0개 확인.
- **인쇄하면 빈 두 번째 쪽이 나옴** → 인쇄용 화면 높이 고침. A4·A3 모두 한 쪽, 용지 크기 정확.
- **1280px 노트북에서 리본 오른쪽(격자·전체 보기)이 잘림** → 좁은 화면에서 리본을 조금 촘촘하게.
- **꼬인 다각형만 있을 때 “몸체를 그려 주세요”라는 엉뚱한 안내** → “몸체 도형이 잘못되어 …” 로 바꿈.
- 도면 출력: 우측면도 구멍 지시가 뷰 이름과 겹치던 것, 플랜지처럼 볼트 원 중심이 부품 가운데면 쓸데없던 좌표 치수.

## 5단계에서 만든 것: 도면 이미지 → 3D

**파일 ▸ 도면 이미지 가져오기**(Ctrl+I), 이미지를 창에 끌어다 놓기, 또는 캡처한 화면을 Ctrl+V로 붙여넣기.
PNG·JPG 사진과 스캔, PDF(여러 쪽이면 쪽을 고름)를 읽는다. AI 없이 영상 처리만 쓴다 (브라우저 백그라운드 스레드).

1. **사진 바로잡기**: 어두운 책상 위 종이를 찾아 네 모서리로 반듯하게 편다(원근 보정). 가로세로 비가 A 용지(√2)에 가까우면 √2로 맞춘다.
   모서리가 틀리면 ‘종이 모서리 맞추기’에서 파란 점을 끌어 고친다. 그림자·밝기 차이를 고르게 하고, 기울기(±8°)를 바로잡는다. 옆으로 누운 도면은 90° 돌리기.
2. **치수선 걸러 내기**: 선 굵기를 재서 굵기가 두 가지면 가는 선(치수선·중심선·숨은선·지시선·글자)을 지우고 외형선만 남긴다.
   굵기가 한 가지인 도면도 된다: 외형선에 붙은 지시선 끝은 깎아 내고, 중심선이 지나가 쪼개진 구멍은 다시 합친다.
3. **뷰 찾기**: 안쪽을 둘러싼 큰 외형선 덩어리 = 뷰, 도면 테두리·표제란은 뺀다. 3각법 배치(평면도는 정면도 위, 우측면도는 정면도 오른쪽)로 이름을 붙이고, 고칠 수 있다.
4. **모양 맞추기**: 외형선을 직선·원호로 맞춘다. 수평·수직은 정확히, 직선 사이 둥근 모서리는 모서리 R로, 축에 나란한 사각형은 사각형 도형으로.
   구멍은 원·장공(양끝 반원)·사각형/다각형으로. 지시선 화살표가 닿아 찌그러진 원도 벗어난 점을 빼고 원으로 맞춘다.
   동심원의 바깥쪽(카운터보어·보스일 수 있음)은 처음에 꺼 둔다. 그림에서 구멍을 눌러 켜고 끈다.
5. **크기(척도)**: ‘용지 기준’(이미지가 용지 한 장 전체일 때: 용지 크기 + 표제란의 척도) 또는 ‘아는 길이로’(두 점을 찍고 실제 길이 입력, 꼭짓점에 붙음).
   좌표는 격자(0.1/0.5/1 mm)에, 구멍 지름은 표준 지름(볼트 관통·탭 기초·자리파기)에 붙인다. 같은 지름 구멍이 여럿이고 M2~M12 볼트 관통 구멍 지름이면 규격도 붙인다.
6. **원점 맞추기**: 정면도 왼쪽 아래가 원점, 평면도는 정면도와 같은 X, 우측면도는 정면도와 같은 Z → 세 뷰가 3D에서 정확히 겹친다.
   평면도가 원이고 정면도·우측면도가 같으면 **회전체**로 알아보고 회전축을 원점에 둔다.
7. **밑그림**: 가져온 도면의 선을 제도판 각 뷰 밑에 흐리게 깔아 준다(상태 표시줄 ‘도면 이미지’로 켜고 끔). 치수 숫자를 보며 고치기 쉽다.
   프로젝트 파일(.json)을 저장하면 밑그림도 함께 들어간다.

검증: 예제 6개를 도면 → 이미지(8 px/mm)로 만들고 다시 읽으면 3D 크기·부피(깊이 정보가 없는 예제)·구멍 수가 원래와 같다(자동 시험).
브라우저에서는 PDF, 7° 돌아간 그림자 진 사진(JPG), 아는 길이로 척도 정하기까지 확인했다.

아직 안 되는 것 (뒤로):
- **깊이**: 막힌 구멍·포켓·카운터보어 깊이는 한 뷰만 보고 알 수 없어서 관통으로 가져온다 → 속성 패널에서 깊이를 넣는다. (숨은선으로 깊이 추정은 다음에)
- 1각법 도면(평면도가 아래), 단면도, 치수 숫자 읽기(OCR), 손으로 그린 스케치, 해상도가 아주 낮은 이미지(선 굵기 1~2픽셀).
- 작은 모따기(약 1 mm 이하)는 직각으로 읽힐 수 있다.

## 6단계에서 만든 것: 다른 CAD의 3D 파일 → 2D 도면

**파일 ▸ 3D 파일 가져오기 (STEP·STL)**, 또는 파일을 창에 끌어다 놓기.

- **STEP**: OpenCascade로 정확한 곡면 그대로 읽어 3면도(외형선·숨은선)를 만든다. 축이 X·Y·Z 방향인 원통 구멍을 찾아서
  관통/깊이, 같은 축의 큰 원통은 카운터보어로 묶어 도면에 “2×Ø6.6 구멍 관통 · 카운터보어 Ø11 깊이 6.5” 같은 지시와 중심선·위치 치수를 붙인다.
- **STL**: 삼각형 메쉬라서 직접 만든 투영을 쓴다 — 두 면이 25° 넘게 꺾이는 모서리, 열린 가장자리, 앞뒤가 바뀌는 윤곽선을 고르고
  깊이 버퍼(z-buffer)로 보이는 선/숨은선을 나눈다. 원은 여러 각형으로 그려지고 구멍 지시는 붙지 않는다.
- **방향 돌리기**: 다른 CAD는 위쪽 축이 다를 수 있어서 위쪽 표시줄의 X ↻ Y ↻ Z ↻로 90°씩 돌린다(프로젝트에 저장).
- 가져온 파일은 브라우저 IndexedDB에 보관하고, 프로젝트 파일(.json)로 저장하면 3D 파일도 함께 들어간다.
  3D 보기·도면 출력·DXF/SVG/인쇄·AI 설계 검토가 그대로 된다. STL로 가져온 모델은 STEP으로 저장할 수 없다(면 정보가 없음).
- 검증: 예제를 STEP·STL로 저장했다가 다시 가져오면 크기·부피가 같고(STL 1% 안), STEP의 구멍·카운터보어·막힌 구멍을 찾는다(자동 시험).

## 도면 검토: “제대로 된 설계가 아닌 것”도 읽고 알려 주기

손·태블릿 스케치, 사진, 정식 도면을 읽고 잘못된 점과 확인할 점을 알려 준다. 두 단계로 나뉜다.

1. **AI 없이 (도면 이미지 가져오기 창의 ‘5. 검토’)**: 어두운 바탕(태블릿 검은 화면)은 자동으로 뒤집어 읽는다. 그림으로 알 수 있는 것만 알려 준다 —
   뷰끼리 같아야 할 길이(정면도·평면도 가로, 정면도·우측면도 높이, 평면도 세로·우측면도 가로)가 다른지, 3각법 배치가 아닌지, 빗금(해칭)이 단면이 아닌 뷰에 있는지,
   해상도가 낮은지, 손으로 그린 선인지, 확실하지 않아 꺼 둔 구멍 후보.
2. **AI로 읽고 검토 (파일 ▸ 도면 검토, 또는 가져오기 창의 버튼)**: 손글씨 치수·메모·뷰 이름을 읽는 일은 영상 처리만으로는 할 수 없어서 AI(Claude)를 쓴다(API 키 필요).
   그림 1~6장(한 조립품의 여러 부품, 같은 부품의 여러 버전)을 한꺼번에 보내면
   - 적힌 치수끼리의 합·차, 뷰끼리, 고친 버전끼리, 조립되는 부품끼리 맞는지 **직접 계산해서** (예: 2×117×sin15° = 60.56) 알려 주고,
   - 빠진 치수, 애매한 치수, 규격 부품(볼트·탭·O-링·나사 물림), 도면 관례(투상법·빗금·소수점), 만들기·강도·안전 문제를 찾고,
   - 설계자에게 물어야 할 것을 질문으로 남기고, 모양이 정해진 그림은 **3D 초안**으로 바로 만들 수 있다.
   - 결과를 누르면 그 그림의 해당 위치에 상자가 표시된다.

## 7단계에서 만든 것: 작업 기반 (작업이 사라지지 않게)

- **7.1 프로젝트 보관함** — 파일 ▸ 내 프로젝트 (Ctrl+Shift+O)
  - 브라우저 IndexedDB에 프로젝트를 여러 개 보관. 카드마다 3D 썸네일(3D가 만들어질 때마다 갱신)·이름·요약(도형·구멍·변수 수)·수정 시각
  - 열기·복제·이름 바꾸기·찾기, 삭제는 **휴지통**으로(30일 안에 되살리기, 지나면 버전 기록과 함께 영구 삭제)
  - 새 부품·예제·파일 열기·STEP/STL 가져오기·도면 이미지 가져오기·AI 초안은 모두 **새 프로젝트**로 열린다 — 앞의 작업이 덮이지 않음
  - 고칠 때마다 0.8초 모아서 보관함에 저장(상태 표시줄 `✓ 저장됨`). 브라우저 저장본(localStorage)에도 바로 쓰고 어느 프로젝트인지(_id) 함께 적어서, 창이 갑자기 닫혀도 다음에 이어 감
  - 6단계까지의 자동 저장 한 칸은 처음 켤 때 보관함의 프로젝트 하나로 옮김. 빈 새 부품을 새로 고침하면 예제로 바뀌던 문제도 고침
  - 아무 프로젝트·버전도 가리키지 않는 큰 파일(가져온 3D, 밑그림)은 시작할 때 정리
- **7.2 버전 기록** — 파일 ▸ 버전 기록, 지금 버전 저장(Ctrl+Shift+S), 상태 표시줄 `✓ 저장됨`을 눌러도 열림
  - 자동 버전: 고치는 동안 10분마다 하나(프로젝트마다 최근 50개), 큰 변화 직전(버전 되돌리기, 가져온 3D 파일 닫기)
  - 직접 저장한 버전은 이름을 붙이고, 지우기 전까지 남는다
  - 버전마다 썸네일, “지금과 비교”(이름, 도형 추가·삭제·바뀜 개수, 변수, 두께, 도면 설정, 3D 파일)
  - **되돌리기**는 실행 취소로 다시 돌아갈 수 있고(Ctrl+Z), 되돌리기 전 상태도 버전으로 남김. 버전을 **새 프로젝트로** 꺼낼 수도 있음
- **7.3 안전장치**
  - **전체 백업**: 모든 프로젝트·버전·3D 파일·밑그림을 JSON 파일 하나로 내보내고 가져오기. 같은 것은 건너뛰고, 고친 프로젝트와 겹치면 “(백업)”으로 따로 넣음
  - 같은 프로젝트를 두 탭에서 열면 양쪽에 경고, 한쪽에서 고치면 다른 쪽에 “다시 불러오기”
  - 저장 공간이 차거나 저장에 실패하면 알림(내 프로젝트·파일로 저장 버튼), 예상 못 한 오류도 알림(“작업은 자동 저장돼 있어요”, 새로 고침 버튼)
  - 설정에 저장 공간 사용량, 브라우저가 지우지 않게 보호 요청(persistent storage)
- **7.4 앱으로 설치·오프라인 (PWA)**
  - 앱 아이콘·설치 정보(manifest), 파일 ▸ 앱으로 설치(Chrome·Edge). .json·.step·.stp·.stl 파일을 앱으로 열기 등록
  - 빌드할 때 서비스 워커(sw.js)를 만들어 모든 파일(3D 엔진 23MB, PDF 읽기 포함 17개)을 처음 열 때 받아 둔다 → 인터넷 없이 새로 고침해도 그리기·3D·도면·저장 동작
  - 새 버전이 올라오면 “지금 업데이트” 알림(저장한 뒤 바꿈), 인터넷이 끊기면 상태 표시줄에 “오프라인”
- **7.5 실험 기능 표시** — 도면 이미지 가져오기·AI 도면 검토·AI 설계 검토에 “실험” 표시. 설정 ▸ 실험 기능 보이기를 끄면 메뉴·버튼·단축키·끌어다 놓기에서 빠진다(알림으로 안내)
- 검증: 단위 시험 11개(버전 요약·비교·정리, 보관함·휴지통·버전 50개 제한·파일 정리·백업 왕복 — 가짜 IndexedDB), 브라우저 시험 54개
  (프로젝트 오가기·새로 고침·복제·이름 바꾸기(실행 취소 가능)·휴지통·검색, 버전 저장·비교·되돌리기·Ctrl+Z, 백업 → 전부 지움 → 복원, 두 탭, 실험 기능 끄기, 오류 알림,
  **인터넷을 끊고 새로 고침해도 3D·도면 동작**), 예전 자동 저장 이전 시험, 이전 단계 시험(검토 32개, 3D 가져오기 11개) 그대로 통과

## 8단계에서 만든 것: 앱 구조

눈에 보이는 기능보다 **앞으로 기능 수백 개를 붙여도 버티는 구조**가 목표였다. 그래도 바로 쓸모 있는 것을 함께 넣었다.

- **8.1 명령 시스템**: 앱의 동작 83개를 “명령”(이름·분류·찾기용 별칭·단축키·쓸 수 있는 조건·실행)으로 등록.
  메뉴·리본 버튼·단축키·명령 찾기가 모두 같은 명령을 부른다. 단추의 단축키 표시와 흐림(쓸 수 없음)·강조(켜짐)도 명령에서 온다.
  - 단축키를 **자판 위치**로 읽어서 **한글 입력 상태에서도** V·R·Ctrl+Z 같은 단축키가 그대로 동작 (예전에는 한글 상태면 안 됐음)
  - 위쪽에 **편집 ▾ · 보기 ▾ 메뉴** 추가 (명령 목록으로 만들어짐, 켜진 것은 ✓)
- **8.2 명령 찾기 (Ctrl+K, F1, 위쪽 ‘⌕ 명령 찾기’)**: 이름으로 아무 기능이나 찾아 실행. **한글 초성**(ㅅㄱㅎ → 사각형 그리기), 영어(undo, print, circle),
  띄어쓰기 없이도. 최근 쓴 명령이 위로, 지금 쓸 수 없는 명령은 흐리게(이유 표시)
- **8.3 실행 취소 기록 2.0**: 상태를 통째로 복사하던 방식(100번 제한)을 **바뀐 곳만 기록**하는 방식으로. 1,500개 도형 문서에서 수정 100번 = 약 5KB.
  모든 기록에 이름(“사각형 그리기”, “치수 고치기”, “회전체로” …), Ctrl+Z 때 무엇을 되돌렸는지 알림.
  **편집 ▸ 실행 취소 기록 보기 (Ctrl+Alt+Z)**: 지금까지 한 일 목록에서 눌러 그 단계로 건너뛰기(뒤의 단계는 다시 실행으로 남음). 끌기 한 번은 기록 한 칸
- **8.4 작업 공간 모듈**: 2D 설계·3D 보기·도면 출력이 각각 모듈(자기 화면·보이기/숨기기·명령)이 되었다. 모듈을 붙이면 위쪽 탭·숫자 단축키·명령 찾기에 자동으로 들어가고, 떼면 모두 빠진다.
  **설정 ▸ 개발자 ▸ 예제 작업 공간**으로 붙였다 떼는 것을 직접 볼 수 있다 (`src/workspaces/example.ts`가 새 모듈을 만드는 본보기)
- **8.5 패널 배치**: 왼쪽(트리·변수)·오른쪽(속성·검사) 패널 경계를 끌어 너비 조절, 두 번 눌러 접기(Ctrl+B / Ctrl+Alt+B), 좌우 자리 바꾸기, 처음대로. 새로 고침 뒤에도 그대로
- **8.6 설정 화면 (Ctrl+,)**: 일반(테마 시스템/밝게/어둡게, 언어·단위는 준비 중 표시, 처음 격자), 화면 배치, **단축키 바꾸기**(바꾸기 → 키 누르기, 겹치면 다른 쪽에서 빼고 알림, 하나씩·전체 처음대로),
  실험 기능, 저장 공간, AI(실험, 키 저장), 개발자. 바꾸는 즉시 적용·저장

  ＋ 부품, 3D 파일을 부품으로 가져오기, 다음/이전 부품(Ctrl+Alt+] / [), 명령 찾기에 “부품 열기: 이름”. 위쪽 이름 칸은 문서 이름(부품이 하나면 부품 이름도 같이).

## 10단계에서 만든 것: 스케치 2.0 — 구속 조건

**벤치마킹**: [FreeCAD 스케처](https://wiki.freecad.org/Sketcher_Dialog)(자유도 표시, 다 정해진 스케치 색, 중복·충돌 구속 진단 — [PR #1429](https://github.com/FreeCAD/FreeCAD/pull/1429)),
[SolveSpace system.cpp](https://gitea.suzanne.soy/suzanne.soy/solvespace/src/tag/v2.0/system.cpp)(최소 노름 뉴턴, Jacobian 계수로 자유도),
[planegcs](https://github.com/Salusoft89/planegcs)(FreeCAD 해석기의 WASM판 — 라이선스 때문에 쓰지 않음, 결정 18).
단위는 [Onshape 숫자 칸](https://cad.onshape.com/help/Content/numeric-fields.htm)(맨 숫자는 기본 단위, 식 결과는 단위 없음 또는 길이 1제곱까지)·[Fusion 360 매개변수 식](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_Parameter_expression.htm)(맨 숫자는 문서 기본 단위, 단위 없는 값을 치수에 쓰면 `* 1 in`을 붙여 맞춤)처럼 “단위 없는 숫자는 쓰이는 자리로 정한다”(결정 20).

- **10.1 구속 해석기** (`core/solver.ts`, 직접 만듦): 식(잔차)·해석적 미분, **최소 노름 뉴턴**(가장 적게 움직이는 해) + 수렴이 안 되면 LM 감쇠·선 탐색,
  서로 떨어진 묶음은 따로 풂(union-find). 순서대로 Gram–Schmidt 계수 분석 → **자유도 = 쓰인 변수 − 계수**, 변수별 “정해짐”, 나중에 넣은 **중복 구속** 지목.
  속도(단위 시험): 구속 50개 **0.5 ms**(기준 10 ms), 작은 묶음 500개 **1.8 ms**(기준 100 ms), 한 덩어리 200개 **17 ms**
- **10.2 구속 모델** (`core/constraints.ts`): 뷰마다 구속 목록. 대상 = 점(사각형 꼭짓점·중심, 원 중심, 장공 끝, 다각형 꼭짓점, **원점**), 직선(사각형 변, 다각형 변, 장공 축, **가로·세로 축**), 원.
  종류 16가지: 일치·동심·수평·수직·평행·직각·같게(길이·지름)·접선(선-원, 원-원)·대칭·점-선 위·중점·고정 + 치수 구속 거리·가로 거리·세로 거리·각도(값 또는 **변수 식**).
  도형의 매개변수(사각형 x·y·w·h, 원 중심·반지름 …)를 그대로 해석기 변수로. 잠근 치수(🔒·식)는 고정 변수. 지운 도형의 구속은 저장·열 때 정리
- **10.3 모든 편집과 연결**: 끌기·치수 칸·속성·변수·두께·구멍 깊이 — 어떤 편집이든 끝나면 바뀐 값은 붙잡고 나머지를 풀어 조건을 지킨다.
  풀 수 없으면 그 편집 전체를 되돌리고 “구속 조건과 맞지 않아 되돌렸어요 (…)”. 끌 때는 그 프레임만 되돌림 → 다 정해진 도형은 끌어도 안 움직임
- **10.4 구속 도구·표시**: 리본 ‘구속’ 묶음(16개) + 명령 찾기(“ㅅㅍ” → 수평) + <kbd>K</kbd>(거리 치수). 대상을 차례로 누르면 생성(맞는 대상만 강조),
  제도판에 구속 기호(H·V·∥·⊥·=·◎·T·⌖…)와 치수 구속(값 눌러 고치기, 식 가능), **다 정해진 도형은 진한 선**, 리본 끝 **“자유도 N / ✓ 다 정해짐 / ⚠ 안 풀림”**.
  속성 패널에 그 도형의 구속 목록(눌러 고르기·✕ 지우기), 고른 구속의 대상·값. Delete로 지우기, 실행 취소 기록에 “구속: 가로 거리”
- **10.5 검사·안내**: 이미 정해진 것에 구속을 더하면 만들지 않고 “중복 구속” 알림, 부딪치는 값은 되돌리고 알림, 열 때 지켜지지 않는 구속은 검사 목록에 오류, 필요 없는 구속은 정보
- **10.6 길이 단위 mm/inch**: 문서마다 단위(상태 표시줄 **mm/inch 단추**, 명령 “길이 단위 바꾸기”, 설정의 “새 문서 길이 단위”). 값은 늘 mm로 저장하고 표시·입력만 문서 단위.
  식 안에 단위: `10 mm`, `0.5 in`, `2"`, `1 cm`, `(L/2) mm`. 단위 없는 숫자는 길이와 더하면 문서 단위, 곱하기·나누기에서는 배수, 길이 칸에 들어가면 문서 단위(`m`은 기어 모듈처럼 변수 이름으로 남김).
  **단위를 바꿔도 모양 그대로**: 식을 새 단위로 계산해도 같은 값이 되게 고쳐 씀(`80` → `80 mm`, `L/4` → `(L/4) mm`, inch→mm `1` → `25.4`), 돌아오면 원래 글자로.
  inch 문서는 격자도 0.05"·0.1"·1/8"·1/4"·1", 검사 문구·구멍 지시·좌표·3D 크기·부피(in³)도 inch, **도면 치수·표제란(“3각법 · inch”)·DXF($INSUNITS = inch, 좌표도 inch)**
