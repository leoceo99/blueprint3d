# 아이디어 보관함

떠오른 기능은 여기에 먼저 적고, 단계가 끝날 때마다 정리해서 [ROADMAP.md](ROADMAP.md)의 단계에 배치한다.
그 자리에서 바로 만들지 않는 것이 원칙이다 (지금 단계가 흔들리지 않게).

**적는 법**: `- [트랙?] 무엇을 — 왜 (출처, 날짜)`
트랙: 기반 · 부품 · 도면 · 메쉬·게임 · 조립 · 제조 · 플랫폼 · 연구 · ?(모름)

## 새로 들어온 것 (아직 분류 전)

- [부품] 끌 때 “구속 때문에 못 움직임”을 손잡이 색·커서로 미리 알려 주기 (지금은 놓은 뒤 안 움직임만 보임) (10단계 정리, 2026-11)
- [부품] 각도·질량 단위, 변수마다 단위 칸 (Fusion 사용자 변수처럼) — 지금은 `80 mm`처럼 식에 직접 붙임 (결정 20, 2026-11)
- [플랫폼] 설치 파일 코드 서명(윈도우 인증서·맥 공증) — 지금은 처음 열 때 경고가 뜸 (12단계 정리, 2026-11)
- [플랫폼] 앱 자동 업데이트 (Tauri updater) — 지금은 새 설치 파일을 받아 덮어 설치 (12단계 정리, 2026-11)
- [플랫폼] 앱 창에 끌어다 놓은 .b3d도 Ctrl+S로 그 자리에 저장 (Tauri 끌어 놓기 이벤트로 경로 받기) — 지금은 웹처럼 열려서 처음 저장 때 위치를 물음 (12단계 정리, 2026-11)
- [도면] 펜(스타일러스)으로 치수 위치 잡기·손글씨 메모 — 패드 앱(23단계) 때 (12단계 정리, 2026-11)

- [도면] 구멍 피처(카운터보어·탭)의 규격을 도면 구멍 지시에 그대로 (지금은 3D 모양에서 읽은 지름만) (13단계 정리, 2026-11)
- [부품] 3D 경로 스윕(여러 평면을 잇는 배관·호스 경로) — V1 자동차의 냉각수 배관에 필요 (13단계 정리, 2026-11)
- [부품] 스케치에 3D 모서리 끌어오기(투영 선을 스케치 도형으로) — 지금은 밑그림에 붙기만 (13단계 정리, 2026-11)
- [부품] 기준면·기준축 피처(각도 평면, 세 점 평면) — 면이 없는 곳에 스케치할 때 (13단계 정리, 2026-11)
- [부품] 피처 여러 개를 한꺼번에 패턴할 때 미리 보기 그림자 (Fusion처럼) (13단계 정리, 2026-11)

## 배치된 것

- [메쉬·게임] Blender처럼 게임에 쓸 수 있는 모델을 만드는 기능 — 시중 도구를 하나로 (사용자, 2026-11) → 15~18, 20, 22단계
- [연구] AI와 의논하며 설계 — 원하는 부품을 대화로 정해 가기 (사용자, 2026-11) → R3 (R2 결정 뒤)
- [연구] 도면 이미지를 제대로 인식하고 사고하도록 개혁 (사용자, 2026-11) → R1
- [연구] AI 대신 다른 방안 찾기 (사용자, 2026-11) → R2
- [기반] 버전 기록·되돌리기, 오프라인 설치, 자동 복구 (사용자, 2026-11) → 7단계 ✅ 완료
- [도면] STEP으로 받은 부품에서 치수가 다 들어간 DWG 도면 (사용자, 2026-11-07) → 11단계 ✅ (치수) · 12단계 ✅ (DWG 저장)
- [플랫폼] 브라우저가 아닌 설치형 앱, 나중에 패드 (사용자, 2026-11-07) → 12단계 ✅ · 23단계
- [검증] 모든 단계가 끝나면 앱으로 휘발유 자동차를 직접 설계해서 전체가 잘 되는지 확인 — 외형 + 엔진·라디에이터·냉각수 배관·컨덴서·배터리 등 필수 내부만, 자료가 가장 많은 차로 (사용자, 2026-11-10) → V1
- [부품] 선택 치수와 구속 치수 글자가 겹침 (10단계 화면 사진, 2026-11) → 11.5 다듬기 ✅

## 제안 (검토 대기)

정리 때 함께 보고 넣을지 정한다.

- [부품] 재질을 정하면 무게·무게 중심·대략의 가격 계산
- [도면] 도면을 고치면 3D가 따라 바뀌는 양방향 (치수 숫자를 고치면 부품이 바뀜) — 11단계 치수 모델 위에 14단계(도면 2.0)에서
- [조립] 나사·볼트를 고르면 구멍 규격이 자동으로 맞춰지는 “체결 마법사”
- [제조] 3D 프린팅 예상 시간·재료량, 레이저 절단용 DXF 정리
- [메쉬·게임] 게임 엔진에서 바로 미리보기(웹에서 간단한 장면 실행)
- [플랫폼] 휴대폰·태블릿에서 보기 전용(도면 확인, 3D 돌려 보기)
- [기반] 튜토리얼·예제 모음, 처음 쓰는 사람 안내
